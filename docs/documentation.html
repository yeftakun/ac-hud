01 / InstallationInstalasi

Download the Windows installer or portable ZIP from the GitHub releases. Start AcHud.exe, select the Assetto Corsa installation folder, and use Install / Update Bridge.Unduh installer Windows atau portable ZIP dari GitHub releases. Jalankan AcHud.exe, pilih folder instalasi Assetto Corsa, lalu gunakan Install / Update Bridge.

  1. Install or extract AC Display Unit.Install atau ekstrak AC Display Unit.
  2. Choose the Assetto Corsa folder in the launcher.Pilih folder Assetto Corsa di launcher.
  3. Install the CSP bridge.Install CSP bridge.
  4. Enable AC HUD Bridge in Content Manager's Python Apps.Aktifkan AC HUD Bridge di Python Apps Content Manager.
  5. Open Home, Editor, or Display from the launcher.Buka Home, Editor, atau Display dari launcher.

02 / Local networkJaringan lokal

The launcher hosts the web interface locally. To use a phone or another display, connect it to the same Wi-Fi network and open the LAN address shown by the application. If it cannot connect, check Windows Firewall, hotspot client isolation, and that the server is listening on the expected port.Launcher menjalankan web interface secara lokal. Untuk memakai HP atau display lain, hubungkan ke Wi-Fi yang sama dan buka alamat LAN yang ditampilkan aplikasi. Jika tidak terhubung, periksa Windows Firewall, isolasi client hotspot, dan port server.

03 / CSP bridge

The CSP bridge provides additional intervention and game-state signals such as ABS and TC activity. Assetto Corsa original, Content Manager, and CSP are required for the tested production setup. CSP 0.2.11 was used during testing.CSP bridge menyediakan sinyal tambahan seperti aktivitas ABS dan TC. Assetto Corsa original, Content Manager, dan CSP dibutuhkan untuk setup production yang dites. Pengujian dilakukan dengan CSP 0.2.11.

04 / ArchitectureArsitektur

The frontend is a React and TypeScript application. The separate backend repository provides the Config API, telemetry ingest, Server-Sent Events broadcast, shared-memory collector, CSP bridge integration, and Windows launcher.Frontend adalah aplikasi React dan TypeScript. Repository backend terpisah menyediakan Config API, telemetry ingest, broadcast Server-Sent Events, shared-memory collector, integrasi CSP bridge, dan launcher Windows.

Assetto Corsa → shared memory / CSP bridge → collector → backend → browser display
                                      ↘ layout profile API → editor
