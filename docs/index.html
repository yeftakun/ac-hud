QUESTIONS

Before you start.Sebelum mulai.

What do I need to run it?Apa yang dibutuhkan untuk menjalankannya?+

Use Windows x64 with the original Assetto Corsa, Content Manager, and Custom Shaders Patch. CSP was tested with version 0.2.11. The laptop and secondary display should be on the same local network for LAN access.Gunakan Windows x64 dengan Assetto Corsa original, Content Manager, dan Custom Shaders Patch. CSP telah dites dengan versi 0.2.11. Laptop dan display kedua sebaiknya berada di jaringan lokal yang sama untuk akses LAN.

Does it require an internet connection while driving?Apakah perlu internet saat berkendara?+

No internet service is required for the local HUD flow. The launcher, backend, collector, and browser display run on your computer and local network.Tidak diperlukan layanan internet untuk alur HUD lokal. Launcher, backend, collector, dan browser display berjalan di komputer dan jaringan lokal.

Can I use a phone as the display?Apakah HP bisa dipakai sebagai display?+

Yes. Start AC Display Unit on the laptop, then open the LAN address shown by the application on a phone connected to the same Wi-Fi network. Firewall rules and hotspot isolation can affect access.Bisa. Jalankan AC Display Unit di laptop, lalu buka alamat LAN yang ditampilkan aplikasi pada HP yang terhubung ke Wi-Fi yang sama. Firewall dan isolasi hotspot dapat memengaruhi akses.

How do I change the HUD layout?Bagaimana cara mengubah layout HUD?+

Open Editor, select a widget, then drag or resize it. Widget properties can change dimensions, position, colors, value size, and z-index. Save applies changes; Import and Export move layouts as JSON files.Buka Editor, pilih widget, lalu drag atau resize. Properties widget dapat mengubah ukuran, posisi, warna, ukuran nilai, dan z-index. Save menerapkan perubahan; Import dan Export memindahkan layout sebagai file JSON.

Is the tyre wear value the same as the in-game visual indicator?Apakah nilai tyre wear sama dengan indikator visual di dalam game?+

The current widget reads the tyre wear field exposed through Assetto Corsa shared memory. Depending on the car and physics source, it may not change at the same rate or represent exactly the same visual indicator as the in-game HUD.Widget saat ini membaca field tyre wear dari shared memory Assetto Corsa. Tergantung mobil dan sumber physics, nilainya bisa tidak berubah dengan laju yang sama atau tidak persis merepresentasikan indikator visual di HUD in-game.

Where can I find deeper technical documentation?Di mana dokumentasi teknis selengkapnya?+

See the documentation page for installation notes, architecture, telemetry, CSP bridge setup, and development information.Lihat halaman dokumentasi untuk catatan instalasi, arsitektur, telemetry, setup CSP bridge, dan informasi pengembangan.
